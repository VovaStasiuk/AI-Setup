# Design System

This is a documentation and CLI/template project. There is no product UI yet.

## Visual Direction

- Keep docs plain, direct, and scannable.
- Prefer command examples and tables over long prose.
- Avoid marketing-heavy language.
- Use ASCII-safe Markdown unless a file already uses non-ASCII intentionally.

## Theme Discovery

If this project later gains a website or UI, use `human-ui-designer` theme discovery first. Reference collections such as getdesign.md and awesome-design-md may inform palette/typography options, but final choices must become concrete project `DESIGN.md` rules before implementation.

## Future UI

If a web UI is added later, create a feature-level design brief before implementation.
