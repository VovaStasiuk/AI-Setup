# Project Context

AI Setup is a portable installer/template project for Claude, Codex, Gemini, and related AI coding workflows.

It installs global skills, Claude command wrappers, Claude/Codex global bootstrap files, and a project starter kit. The source of truth lives in this repository; installed copies/symlinks live under `~/.agents`, `~/.claude`, and `~/.codex`.

## Important paths

- Installer: `install.sh`
- Skills: `setup/skills/`
- Claude commands: `setup/claude-commands/`
- Global bootstraps: `setup/global-files/`
- Project starter kit: `setup/project-kit/`
- Docs: `docs/`
- Profiles: `profiles/`
