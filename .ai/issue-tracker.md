# Issue Tracker

Current mode: local Markdown.

## Local Markdown

- Specs live in `.ai/specs/`.
- Tickets live in `.ai/tickets/`.
- Use one ticket per file when persisting tickets.
- Number ticket files in dependency order, for example `01-add-profile-validation.md`.
- Use lower-case kebab-case after the number.
- Include `Blocked By`, `Acceptance Criteria`, `Test Seam`, `Verification`, and `Review Focus` sections in every ticket.
- Use `Blocked By: None.` for frontier tickets that can start immediately.

## External Trackers

No external tracker is configured for this repo. Ask before creating or updating GitHub, Linear, Jira, or other external issues.
