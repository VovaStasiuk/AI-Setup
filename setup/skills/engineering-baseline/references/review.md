# Review Defaults

- Lead with findings, ordered by severity.
- Prioritize bugs, regressions, security issues, data leaks, race conditions, missing tests, and user-visible breakage.
- Anchor findings to concrete files, lines, diffs, or reproducible behavior.
- Avoid generic style commentary unless it hides a real maintenance or correctness risk.
- If no issues are found, say so and name remaining test gaps or uncertainty.
- For important self-review, route to another model/tool when available.
