# Design Defaults

- Inspect existing UI before proposing new visual direction.
- The source of truth is project design documentation and existing product UI, not a generated image.
- Prefer dense, usable product interfaces for operational tools; avoid generic AI dashboard tropes.
- Define layout, typography, color roles, component states, responsive behavior, and anti-patterns before coding.
- Verify implementation with screenshots when practical.
- If design direction is missing or conflicting, ask before guessing.
