# Concise Communication

Use this as optional communication discipline, not as an engineering workflow.

## Rules

- Prefer short, direct sentences.
- Keep status updates compact.
- Preserve exact commands, file paths, decisions, risks, and verification details.
- Drop filler, praise, and repetition.
- Do not use full Caveman style unless explicitly requested.
- Return to normal precision for security warnings, irreversible actions, complex plans, or user confusion.
